## Роль и задача

Ты — senior frontend-инженер. Собери с нуля финтех-приложение на Next.js «личный кабинет банка нового поколения» с управлением фиатными и крипто-активами. Код чистый, типизированный, компонентный. Комментарии — только там, где логика неочевидна.

## Стек

- **Next.js 16 (App Router) + React 19 + TypeScript** (strict). Версия Next свежая: перед использованием API сверяйся с `node_modules/next/dist/docs/` (см. AGENTS.md). `middleware.ts` → `proxy.ts`, в `error.tsx` проп `retry` (не `reset`).
- **next-intl** — i18n (ru, en), язык в URL: `/ru/...`, `/en/...`
- **Tailwind CSS v3** — стили, тёмная премиум-тема по умолчанию (токены в `tailwind.config.ts`)
- **lucide-react** — иконки
- **recharts** — графики
- **Redux Toolkit** (`@reduxjs/toolkit` + `react-redux`) — стор (баланс, юзер, тема), стор создаётся на запрос через `StoreProvider`
- Данные — **мок-слой** (`src/mocks`), без реального бэкенда

## Архитектура папок

```
src/
  app/
    [locale]/     # корневой layout (html, провайдеры), страницы, error/not-found
      app/        # кабинет: layout с Sidebar + Topbar, страницы /app/*
  proxy.ts        # редирект на локаль (next-intl) + защита /app
  i18n/
    messages/     # en.json (источник ключей), ru.json
    routing.ts    # локали; navigation.ts — Link/useRouter с учётом локали
  components/
    ui/           # атомы: Button, Card, Input, Badge, Table, Modal
    layout/       # Sidebar, Topbar, Logo, переключатели темы и языка
    charts/       # обёртки над recharts
  features/
    auth/         # логин/регистрация (моковая)
    accounts/     # счета/кошельки
    transactions/ # список и фильтры транзакций
    transfer/     # форма перевода
  store/          # слайсы, makeStore, StoreProvider, cookie-персистентность (тема, сессия)
  mocks/          # моковые данные + фейковые API-функции с задержкой
  lib/            # утилиты: формат валют, дат, cn()
  types/          # общие типы
```

## Страницы и логика (типовой финтех-флоу)

Все пути ниже — без префикса локали (`/app` = `/ru/app` или `/en/app`).

1. **Landing (`/`)** — публичная:
   - Hero: заголовок, подзаголовок, CTA «Открыть счёт» / «Войти».
   - Секции: преимущества (3–4 карточки), «Фиат и крипто в одном месте», тарифы (3 плана), FAQ, футер.
2. **Auth (`/login`, `/register`)**:
   - Формы с валидацией (react-hook-form + zod).
   - Моковая аутентификация: любой валидный email + пароль ≥ 8 символов → редирект на дашборд, флаг в сторе.
   - Защита `/app/*` в `proxy.ts` по cookie моковой сессии (`orion-session`).
3. **Dashboard (`/app`)** — обзор:
   - Суммарный баланс (в базовой валюте), карточки по активам, график баланса за период, последние 5 транзакций.
4. **Accounts / Wallets (`/app/accounts`)**:
   - Список счетов (фиат) и кошельков (крипто) с балансами, курсом, кнопками «Пополнить/Вывести».
5. **Transactions (`/app/transactions`)**:
   - Таблица с фильтрами (тип, валюта, дата, статус), пагинация, поиск.
6. **Transfer (`/app/transfer`)**:
   - Форма перевода: выбор счёта-источника, получатель, сумма, валюта, комиссия (расчёт), подтверждение в модалке.
7. **Settings (`/app/settings`)**:
   - Профиль, смена темы, заглушки безопасности (2FA-переключатель, сессии).

## Требования к качеству

- **TypeScript strict**: без `any`, все пропсы и данные типизированы (`src/types`).
- **UI-кит переиспользуемый**: `Button` с variant/size, `Card`, `Input`, `Badge`, `Table`, `Modal`.
- **Дизайн-токены** в `tailwind.config` (цвета brand/surface/muted, радиусы, тени). Тёмная тема, аккуратная типографика, читаемые контрасты.
- **Адаптивность**: sidebar сворачивается в бургер на мобильном.
- **Форматирование**: валюты и крипто через `Intl.NumberFormat`, даты через утилиту.
- **Состояния**: loading (скелетоны), empty, error — для списков и форм.
- **Доступность**: семантические теги, `aria-*` на интерактиве, фокус-стили.
- **i18n**: никаких захардкоженных строк в UI — только `useTranslations`/`getTranslations`. Новый ключ добавляется сразу в `en.json` и `ru.json` (компилятор проверит, что в `ru.json` есть все ключи `en.json`). Синтаксис ICU: `{name}`, не `{{name}}`. Ссылки и навигация — только из `@/i18n/navigation`.

## Мок-слой

- `mocks/user.ts`, `mocks/accounts.ts`, `mocks/transactions.ts`.
- Фейковые API-функции возвращают `Promise` с `setTimeout` (имитация задержки), чтобы работали состояния загрузки.
- Никаких реальных ключей, паролей или внешних запросов.
